Cómo usarlo

  1. El celular tiene que estar conectado a la misma red Wi-Fi que esta PC.
  2. Si Windows pregunta si StoryForge puede usar la red, permítelo en redes privadas.
  3. En el celular, usa "Agregar a la pantalla de inicio" del navegador para abrirlo como una app.
  4. El enlace lleva una clave de acceso: no lo compartas. Sirve también después de reiniciar el servidor.
  5. Deja esta PC encendida mientras escribes: el modelo corre aquí.

No abras el mismo proyecto a la vez en la ventana de StoryForge y en el celular: cada uno guardaría encima de los cambios del otro.
